# Prepare evidence

Prepared 2026-09-26. The fixed corpus contains 120 distinct 3-SAT formulas: 20 hand cases and 100 reproducible seeded random cases, with 64 YES and 56 NO. Sizes range from 0 to 6 variables. `generate_cases.py` fixes inputs and seeds before construction.

Run `uv sync --locked` and `uv run --locked python campaigns/lettericity/work/check.py --self-test`. It first runs the copied `research/validate_preparation.py`, regenerates random formulas, recomputes labels with Z3, validates satisfying assignments directly, and crosschecks with exhaustive Boolean assignments. The target Z3 encoding chooses a vertex-order permutation, one letter per vertex, and a directed Boolean decoder; each graph pair imposes exactly its ordered decoder value. Every model is validated by the direct adjacency predicate. An independent finite enumerator tries all orders and letter assignments, accepting only if each directed letter pair receives consistent adjacency requirements. The two methods agreed on all 228 graphs up to four vertices and budgets 0, 1 and 2. Hand cases include a feasible edge, an infeasible mixed graph at budget one, invalid encodings and bad witnesses. An intentionally incorrect candidate with a feasible one-vertex target and NO-SOLUTION extraction was rejected.

Oracle: CPython 3.12.14 and locked `z3-solver` 4.16.0.0. Only `unsat` yields a negative result; `unknown` raises. The finite target crosscheck covers at most four vertices and two letters. The candidate gate inspects up to three target outputs per source instance, so it does not prove universal recovery. No reduction or solution is claimed; zero construction rounds were authorized for this setup.
